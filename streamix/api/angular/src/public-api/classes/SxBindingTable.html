Class: SxBindingTable ​

Defined in: projects/libraries/streamix/angular/src/lib/binding-table.ts:39

Preallocated binding table used by compiler-generated Streamix Angular views.

A table owns N integer binding slots and one renderer-scheduler registration. Source emissions only mark slots dirty. Direct bindings keep the latest emitted value, expression slots re-evaluate once per renderer flush, and listener slots hold a DOM listener plus its remover for teardown.
