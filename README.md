# epikodelabs.github.io

> [!IMPORTANT]
> **This repository contains the source code for the EpikodeLabs website and GitHub Pages deployment.**
>
> It is **not** the source repository for Streamix, Actionstack, or any other EpikodeLabs project.

The contents of this repository are published at:

**https://epikodelabs.github.io**

## Project repositories

For source code, issues, documentation, and contributions, use the corresponding project repository:

* **Streamix** — https://github.com/epikodelabs/streamix-community
* **Actionstack** — https://github.com/epikodelabs/actionstack-community
* **Community discussions** — https://github.com/epikodelabs/streamix-community/discussions

## What belongs here

This repository is only for:

* the Epikode Labs landing page;
* shared website assets;
* pricing and licensing pages;
* organization-level project links;
* GitHub Pages configuration and deployment files.

## What does not belong here

Please do not use this repository for:

* project bug reports;
* feature requests;
* library source-code changes;
* Streamix or Actionstack pull requests;
* technical support questions.

Open issues and pull requests in the relevant project repository instead.

## Development

The site is currently served as a static GitHub Pages website. Changes merged into the publishing branch may affect the public Epikode Labs website.

Please verify links, layout, metadata, and responsive behavior before merging.
